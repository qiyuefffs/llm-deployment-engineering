# 三卷写作与章节模板

## 一、三类章节

| 类型 | 要回答的问题 | 主要结构 |
| --- | --- | --- |
| 教程章 | 应该理解什么、怎样判断、下一步做什么 | 问题、判断规则、机制、最小样例、常见错误、检查清单 |
| 实例章 | 这台设备上具体怎样做、结果是多少 | 结论、边界、环境、步骤、结果、失败、证据、未验证 |
| 证据章 | 数字从哪里来、原始过程是什么 | 来源信息、原文正文、失败记录、测量限制 |

## 二、格式规则

- 每章只有一个 H1；侧栏标题从 H1 或 front matter 的同一个标题生成。
- 命令、参数、版本、数字和失败现象优先引用 R 正文，不在多个页面复制整张结果表。
- 结果表中的数字必须带单位，并注明引擎、HTTP、单请求或并发口径。
- 证据声明只在[证据使用与数据边界](evidence-policy.md)维护，章节页脚保留一行链接。
- 不确定或缺失字段写“未记录”或 `TODO(verify)`，不填推测值。

## 三、篇幅原则

- 教程章优先控制在 2,500–5,000 字，超过时按主题拆章。
- 实例章优先控制在 4,000–8,000 字；原始长文留在证据卷。
- 不为达到字数扩写；新增解释必须能回到实例、R/E 正文或结构化测量字段。
