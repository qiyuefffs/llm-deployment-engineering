# 已知口径冲突

| 主题 | 原记录中的冲突 | 正文采信方式 |
| --- | --- | --- |
| Radeon 8060S 内存 | 同页出现约 30GB 系统内存与约 110GB GPU 可用量 | 视为不同观察窗口，实例页要求重新用 `free -h`、BIOS 和设备工具确认；不把 30GB 物理内存当成可容纳全部 BF16 权重 |
| Q4 与 BF16 比较 | “约 5.8 倍”与表内圆整数计算结果并存 | 实例页保留同表原始速度，只给出由明确数值计算的观察比值；不把 5.8 当作同任务质量等价结论 |
| DFlash | 上下文、并发槽位、内存预算和 eager 配置同时改变 | 只报告整套组合观察，不归因给 DFlash 单项 |
| Gemma MTP | 不同并发组使用不同请求规模，镜像 digest 未保存 | 按 c1/c2/c4 分组保留，不合并为单一加速倍数 |
| 并发证明 | 配置写入并发值不等于已压到该并发 | 以实际成功请求数、到达率和逐请求记录为准 |
| 模型容量 | 磁盘文件大小不等于每 token 实际读取量 | MoE 和量化结论按实际执行路径、专家激活和有效带宽解释 |
