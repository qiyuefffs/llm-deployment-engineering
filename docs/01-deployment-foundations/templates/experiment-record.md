# 推理优化实验记录模板

[返回知识体系](../README.md)

每个主要假设单独建一份记录。所有数据待测时留空；不填写示意“提升值”冒充结果。

## 1. 问题、假设与成功标准

- 问题与受影响任务：
- 已有证据、候选瓶颈与其他解释：
- 本轮只改变的主要变量：
- 预期影响的指标与可能代价：
- 实验前约定的质量/SLO/资源门槛：

## 2. 不变条件

- 设备、OS、驱动、Runtime、框架/后端版本：
- 模型 revision、文件哈希、量化、tokenizer/template：
- 启动命令与有效配置（A/B 分别附文件）：
- 采样、输出上限、思考模式、停止条件：
- 输入集来源、哈希、实际长度与质量规则：
- 闭环并发/开放到达率、分布、种子与工具版本：
- 预热、编译/页/前缀缓存策略：
- 电源、温度、其他负载与采样方法：

## 3. 原始记录位置

| 内容 | 文件/目录 | 可公开状态 |
| --- | --- | --- |
| 环境、模型与启动日志 | 待填 | |
| 输入和逐请求结果/响应 | 待填 | |
| CPU/GPU/内存/功率采样 | 待填 | |
| profiler trace（如有） | 待填 | |
| 质量/异常判定 | 待填 | |
| 汇总计算方法或命令 | 待填 | |

## 4. 结果（每轮分别记录）

| 配置/轮次 | 发出/成功/失败 | 实际输入/输出长度 | TTFT P50/P95 | TPOT/ITL 口径 | 输出吞吐/Goodput | 内存/能耗 | 质量 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| A 基线 / 待测 | | | | | | | |
| B 变更 / 待测 | | | | | | | |

- 墙钟测量窗与排空规则：
- 超时、取消、截断、N<2 等样本处理：
- 波动范围、重复策略与异常轮次说明：
- 图表/截图应关注的参数和结果：

## 5. 判断与回滚

- 证据是否支持原假设，仍未排除什么：
- 对质量、TTFT、尾延迟、吞吐、内存和能耗的综合影响：
- 保留/撤回/继续测试，以及理由：
- 适用设备、版本与负载边界：
- 回滚命令/配置引用与回归结果：

没有显著收益、出现质量下降或无法复现，都应如实记录。
