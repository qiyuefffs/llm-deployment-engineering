# 端侧模型适配记录模板

[返回知识体系](../README.md)

复制到自己的项目后填写。空白和“待测”不代表通过；原始日志另存，不把凭证、设备序列号或私人输入放进公开记录。

## 1. 目标与约束

- 项目/日期/负责人：
- 真实任务与可公开输入来源：
- 目标终端与使用方式（离线/常驻/移动）：
- 质量、首个可见答案、完成时间、成功率门槛：
- 上下文/输出/并发要求：
- 内存、存储、功耗/能耗与温度要求：
- 不在本次适配范围的能力：

## 2. 精确兼容记录

| 项目 | 实际值 | 证据文件 |
| --- | --- | --- |
| SoC/CPU/GPU/NPU、RAM/VRAM | 待填 | |
| OS/内核、驱动/固件、SDK/Runtime | 待填 | |
| 编译器/CMake、框架版本/commit、后端 | 待填 | |
| 模型来源/revision/架构/量化/哈希 | 待填 | |
| 模板/分词器/生成参数/许可证 | 待填 | |
| 电源模式、散热、其他负载 | 待填 | |

## 3. 内存预算与有效配置

- 设备权重、KV/状态、运行时、临时空间、余量：
- 主机 RAM 与系统保留：
- ctx/槽位/并发/logical batch/microbatch：
- KV 类型、Attention 后端、线程与卸载：
- 启动命令与有效参数日志：
- 估算和实测不一致之处：

## 4. 分阶段验证

| 验证 | 状态（未测/通过/失败/有条件通过） | 输入与证据 | 限制 |
| --- | --- | --- | --- |
| 后端构建、枚举、初始化 | 未测 | | |
| 模型加载与实际设备执行 | 未测 | | |
| 模板、短/长输入、多轮、停止 | 未测 | | |
| 业务质量与结构化输出 | 未测 | | |
| API 流式、取消与错误输入 | 未测 | | |
| 目标负载性能与内存峰值 | 未测 | | |
| 长时间、休眠/恢复、温控 | 未测 | | |
| 离线安装、重启、升级回滚 | 未测 | | |

## 5. 问题与交付

- 问题现象、最小复现、根因证据与修复：
- 不支持/回退算子与质量风险：
- 可交付的上下文/并发与服务门槛：
- 模型/代码/运行库获取方式与许可证：
- 安装、启动、停止、日志、监控与回滚入口：
- 尚未完成的验证与负责人：

最终结论只能覆盖本表设备、版本与工作负载；不要外推为整个厂商平台均已通过。
