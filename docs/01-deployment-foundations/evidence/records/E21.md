#### 单请求探测

请求参数:

```text
Endpoint: http://127.0.0.1:8080/v1/chat/completions
temperature: 0.4
max_tokens: 160
stream: false
```

返回 timing:

```text
prompt_n: 24
prompt_ms: 396.542
prompt_per_second: 60.5232 tokens/s

predicted_n: 160
predicted_ms: 7960.855
predicted_per_second: 20.0983 tokens/s
```

观察到的行为:

```text
当 max_tokens 较小时，这个 MiniMax chat template 可能把输出预算全部用于 reasoning_content，导致 message.content 为空。
客户端健康检查建议使用更大的 max_tokens，例如 256，并要求模型返回简短最终答案。
```

### 客户端配置建议

OpenAI 兼容客户端建议配置:

```text
Base URL: http://<NODE_IP>:8080/v1
API Key: <API_KEY>
Model: <LOCAL_PATH>
```

如果字段名是 `Base URL`，不要把 `/chat/completions` 填进去。很多客户端会自动在后面追加 `/chat/completions`。

如果是直接 HTTP 请求，则使用:

```text
http://<NODE_IP>:8080/v1/chat/completions
```
