### 已知注意事项

1. 当前 x2 主模型服务是通过当前 shell 会话启动的。如果需要长期驻留，建议改成 `systemd --user` 或一个显式的后台启动脚本，避免终端会话结束时误停服务。
2. 当前 `--ctx-size 8192 --parallel 5` 是总上下文 8K、并发 5，不是每路 8K。
3. x3 的 UFW 只允许 x2 的两个地址访问 `50053/tcp`，这是安全一些的配置。
4. x3 的 Thunderbolt 地址是静态配置 `<NODE_IP>`，不会抢默认路由。
5. `rpc-server` 绑定 `0.0.0.0` 会有安全警告，当前依靠 UFW 做访问限制。
6. MiniMax 模型会输出 `reasoning_content`，短测试如果 `max_tokens` 太小，可能出现 `message.content` 为空；健康测试建议使用 `max_tokens >= 256`。
