# R31 · 双节点模型部署70B-2.0资源调度验证
### 一、准备工作

1. 确认两台机器的IP分别是：

- Head节点IP：`<NODE_IP>`

- Worker节点IP：`<NODE_IP>`

1. 确认模型文件目录存在：

- Head节点模型目录：`/root/models`

- Worker节点模型目录：`/root/models`

1. 确认huggingface缓存路径（如果用）：

- `/root/.cache/huggingface`

1. 确认两台机器docker已经安装，且能访问外网docker镜像仓库，或者提前将镜像拉取好。

### 二、Head节点操作步骤（<NODE_IP>）

##### 1. 拉取docker镜像（如果已经有可跳过）

```text
bash
Copy code
docker pull ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313
```

##### 2. 运行Ray head节点容器

这里最关键的，是**启动Ray时显式绑定head节点的内网IP**，确保worker连接时能找到正确地址：

```text
bash
Copy code
docker run -itd --name node-head-70-GPU \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  --network host \
  --gpus all \
  -v /root/models:/app/models \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313

```

- `--network host` 保证容器使用主机网络，便于节点间通信

- `--ipc=host` 和 `--shm-size=16g` 主要是保证共享内存和IPC支持

##### 3. 进入head容器，启动模型服务

```text
bash
Copy code
docker exec -it node-head bash
```

在容器中运行：

```text
bash
Copy code
python3 -m vllm.entrypoints.openai.api_server --model /app/models/DeepSeek-R1-Distill-Llama-70B \
  --tensor-parallel-size 2 \
  --served-model-name DeepSeek-R1 \
  --max-num-seqs 16 \
  --max-num-batched-tokens 4096 \
  --max-model-len 4096 \
  --gpu-memory-utilization 0.85 \
  --pipeline-parallel-size 2  \
  --disable-custom-all-reduce \
  --port 8000
```

> **注**：如果想自动启动，可以写个shell脚本或者docker entrypoint做启动。

```text
python3 -m vllm.entrypoints.api_server --model /app/models/DeepSeek-R1-Distill-Llama-70B   --tensor-parallel-size 4   --served-model-name DeepSeek-R1   --max-num-seqs 16   --max-num-batched-tokens 4096   --max-model-len 4096   --gpu-memory-utilization 0.85   --disable-custom-all-reduce   --enforce-eager
```

### 五、总结

| 节点 | 关键点 | 命令示例 |
| --- | --- | --- |
| Head节点 | 启动ray head时显式绑定--node-ip-address=<NODE_IP> | ray start --head --node-ip-address=<NODE_IP> --port=6379 --block |
| Worker节点 | 连接head节点的IP，保持一致 | ray start --address=<NODE_IP>:6379 --block |

### 六、示例完整脚本（可根据需要保存为`start_head.sh`和`start_worker.sh`）

##### start_head.sh

```text
bash
Copy code
#!/bin/bash
docker pull ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313

docker run -itd --name node-head \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  --network host \
  -v /root/models:/app/models \
  -v /root/.cache/huggingface:/root/.cache/huggingface \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  -e LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
  bash -c "ray start --head --node-ip-address=<NODE_IP> --port=6379 --block"
```

启动模型服务（进入容器后）：

```text
bash
Copy code
python3 -m vllm.entrypoints.api_server --model /app/models/DeepSeek-R1-Distill-Llama-70B \
  --tensor-parallel-size 1 \
  --served-model-name DeepSeek-R1 \
  --max-num-seqs 16 \
  --max-num-batched-tokens 4096 \
  --max-model-len 4096 \
  --gpu-memory-utilization 0.85 \
  --disable-custom-all-reduce \
  --port 8000
```
