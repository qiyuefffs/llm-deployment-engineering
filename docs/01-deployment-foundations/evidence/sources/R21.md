#### 4. 部署步骤

##### 4.1 llama.cpp 路径

```text
二进制目录: /srv/llm/llamaCPP/
服务端:     /srv/llm/llamaCPP/llama-server
共享库:     /srv/llm/llamaCPP/lib*.so
```

##### 4.2 启动推理服务

**完整启动命令：**

```text
LD_LIBRARY_PATH=/srv/llm/llamaCPP \
/srv/llm/llamaCPP/llama-server \
  --model /srv/llm/models/Qwen3.6-35B-A3B-GGUF/Qwen3.6-35B-A3B-UD-Q4_K_M.gguf \
  --host 0.0.0.0 \
  --port 8080 \
  --ctx-size 16384 \
  --n-gpu-layers 99 \
  --parallel 1 \
  --threads 16 \
  --threads-batch 32 \
  --ubatch-size 1024 \
  --batch-size 4096 \
  --cache-ram 0 \
  --poll 50 \
  --mlock
```

##### 4.3 关键参数说明

| 参数 | 值 | 说明 |
| --- | --- | --- |
| --n-gpu-layers 99 | 99 | 将所有 41 层加载到 GPU Vulkan 后端 |
| --ctx-size 16384 | 16384 | 推理上下文长度（减少 KV 缓存带宽压力） |
| --parallel 1 | 1 | 单槽位模式，节省显存给模型 |
| --threads 16 | 16 | CPU 推理线程数 |
| --threads-batch 32 | 32 | 批处理线程数（充分利用全部核心） |
| --ubatch-size 1024 | 1024 | 微批大小（提升 GPU 并行度） |
| --batch-size 4096 | 4096 | 提示处理批大小 |
| --cache-ram 0 | 0 | 禁用提示缓存，释放内存带宽 |
| --poll 50 | 50 | 减少 GPU 轮询延迟 |
| --mlock | - | 锁定内存页防止 swap |

##### 4.4 停止服务

```text
pkill -f llama-server
```

启动时自动分配情况：

| 资源 | 大小 | 位置 |

| 计算缓冲区 | 1,172 MiB | Vulkan0 (GPU) |
| GPU 总占用 | ~22,653 MiB |  |
| GPU 剩余可用 | ~90,300 MiB |  |

##### 优化说明

- **全部 41 层离线到 GPU**：充分利用 AMD Radeon 8060S 的统一内存架构

- **Flash Attention**：自动启用

- **Gated Delta Net**：fused (自回归) + chunked 模式均在 GPU 启用

- **Graph splits**：降至 2（纯 CPU 时为 844），大幅减少 kernel launch 开销

- **Prompt Cache**：已禁用 (`--cache-ram 0`)，节省内存带宽

- **mlock**：锁定内存页面，防止系统 swap 影响推理延迟

- **采样器优化**：简化为 top-k 采样 (`--sampling-seq k`)，减少开销

#### 6. 推理性能

##### 6.1 基准测试

| 指标 | 纯 CPU (--n-gpu-layers 0) | GPU 初版 (32K ctx) | GPU 优化版 (16K ctx) |
| --- | --- | --- | --- |
| 推理速度 | ~22.9 tok/s | ~47.2 tok/s | ~58.4 tok/s |
| 提示处理速度 | ~57.0 tok/s | ~150 tok/s | ~155 tok/s |
| 每 token 延迟 | ~43.7 ms | ~21.2 ms | ~17.1 ms |
| 内存带宽瓶颈 | CPU 单核 | Vulkan 未调优 | 统一内存带宽极限 |

##### 6.2 优化历程

| 轮次 | 关键改动 | 纯推理速度 |
| --- | --- | --- |
| 初始 | --n-gpu-layers 0 纯 CPU | 22.9 tok/s |
| GPU 加速 | --n-gpu-layers 99 全层 GPU | 47.2 tok/s |
| 参数优化 | ctx 16K + batch 4096 + threads-batch 32 | 58.4 tok/s |
| 极致调优 | + cache-ram 0 + mlock + poll 50 | 58.3 tok/s |

> **结论**：每 token 延迟恒定为 ~17.1 ms，已达到 AMD Radeon 8060S 集成显卡 Vulkan 后端的内存带宽极限。进一步提升需更换更小量化版本（如 IQ4_XS 约 17.7 GB）。

#### 7. 常见问题

##### Q: 启动时提示 `libmtmd.so.0: cannot open shared object file`

**A:** 必须设置 `LD_LIBRARY_PATH=/srv/llm/llamaCPP` 环境变量。

##### Q: 速度太慢 (<30 tok/s)

**A:** 检查日志中 `offloaded X/41 layers to GPU`：

- 如果 `X = 0`，添加 `--n-gpu-layers 99`

- 如果 `X < 41`，减少 `--parallel` 值释放显存

##### Q: Conda 环境找不到

**A:** 运行 `source ~/.bashrc` 或 `/srv/llm/miniconda3/bin/conda init bash`

##### Q: Conda 创建环境提示 ToS 未接受

**A:**

```text
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/main
conda tos accept --override-channels --channel https://repo.anaconda.com/pkgs/r
```
