# R20 · AMD：使用Ollama框架将Llama3.1 8b部署在AMD的GPU
1. 将支持对应AMD设备显卡的Ollama框架设置好

链接：[https://github.com/likelovewant/ollama-for-amd/releases](https://github.com/likelovewant/ollama-for-amd/releases)

1. 使用Ollama部署Llama3.1 8b模型

2. 先启动Ollama serve

3. 然后再开一个cmd窗口，启动Ollama中的Llama3.1 8b模型

python实现Llama3.1 8b模型的流式输出对话

代码：

```text
import requests
import json
import time

OLLAMA_SERVER_URL = "http://127.0.0.1:11434/api/generate"   //本地IP，Ollama框架默认端口11434，可修改


def send_prompt_to_ollama_stream(prompt, model="llama3.1:8b"):
    payload = {
        "model": model,
        "prompt": prompt,
        "stream": True  # 启用流式模式
    }

    try:
        with requests.post(OLLAMA_SERVER_URL, json=payload, stream=True) as response:
            response.raise_for_status()

            # 流式读取响应内容
            print("生成结果（流式输出）：")

            token_count = 0
            start_time = time.time()

            for line in response.iter_lines(decode_unicode=True):
                if line:
                    try:
                        # 尝试解析为 JSON 格式
                        data = json.loads(line)
                        output = data.get("response", "")

                        if output:
                            print(output, end="", flush=True)
                            token_count += len(output.split())  # 估算 token 数量（按空格分割）
                    except json.JSONDecodeError:
                        print("\n无法解析流式响应内容:", line)

            end_time = time.time()
            elapsed_time = end_time - start_time

            # 计算 token/s
            if elapsed_time > 0:
                tokens_per_second = token_count / elapsed_time
                print(
                    f"\n回答完毕。总生成 Token 数量: {token_count}, 时间: {elapsed_time:.2f} 秒, 平均速度: {tokens_per_second:.2f} Token/s")
            else:
                print("\n回答完毕。无法计算生成速度，时间太短。")

    except requests.exceptions.RequestException as e:
        print(f"请求失败: {e}")


if __name__ == "__main__":
    while True:
        user_prompt = input("请输入您的 Prompt（输入 'exit' 退出）： ")
        if user_prompt.strip().lower() == "exit":
            print("程序已退出。")
            break
        send_prompt_to_ollama_stream(user_prompt, model="llama3.1:8b")
        print("\n")  # 每次输出之间添加一个空行

```

1. 可将该代码部署为serve，将输入输出接口使用fastapi封装好，输入端可设置温度，系统prompt，定义角色，流式输出等参数设定；输出为JSON格式，流式输出；

     客户端为界面端，接受Llama3.1 8b 模型输出，也可以在该界面设置模型参数。

1. 客户端启动时，使用bat脚本调用serve，加载模型，传入端口号，可参考sd1.5的写法或者flowy的模型调用写法。
