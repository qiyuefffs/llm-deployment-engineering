# R27 · W7900双卡部署Qwen3:30b-A3b
根据您提供的日志信息，模型加载失败的原因可能是由于 GPU 内存不足或配置不当导致的。特别是 RDNA3 架构的 GPU 在处理大型模型时，可能会遇到页面错误（page fault）或内存访问异常。为了解决这个问题，您可以尝试以下几种方法：([CSDN Ask](https://ask.csdn.net/questions/8384253?utm_source=chatgpt.com))

---

##### ✅ 1. 禁用 V1 引擎并强制使用 ROCm Flash Attention

您已经在启动容器时设置了以下环境变量：

```text
-e VLLM_USE_V1=0 \
-e VLLM_USE_TRITON_FLASH_ATTN=0 \
-e VLLM_ATTENTION_BACKEND=ROCM_FLASH \
-e HSA_ENABLE_SDMA=0
```

这些设置有助于禁用 V1 引擎、关闭 Triton Flash Attention，并强制使用 ROCm Flash Attention，从而减少内存占用。

---

##### ✅ 2. 使用张量并行（Tensor Parallelism）

您可以通过设置 `--tensor-parallel-size` 参数来启用张量并行，例如：([vLLM](https://vllm.hyper.ai/docs/getting-started/troubleshooting/?utm_source=chatgpt.com))

```text
vllm serve . \
  --served-model-name Qwen3-30B-A3B \
  --host 0.0.0.0 --port 8000 \
  --enable-auto-tool-choice \
  --tool-call-parser hermes \
  --trust-remote-code \
  --tensor-parallel-size 2 \
  --gpu-memory-utilization 0.8
```

这将模型拆分到多个 GPU 上，分散内存负载，从而降低单个 GPU 的内存压力。([vLLM](https://vllm.hyper.ai/docs/getting-started/troubleshooting/?utm_source=chatgpt.com))

---

##### ✅ 3. 降低 GPU 内存利用率

通过设置 `--gpu-memory-utilization` 参数，您可以控制每个 GPU 的内存使用比例，例如：

```text
--gpu-memory-utilization 0.8
```

这将限制每个 GPU 使用最多 80% 的显存，避免因内存不足导致的崩溃。

---

##### ✅ 4. 检查 GPU 驱动和硬件兼容性

确保您的 GPU 驱动和硬件与 vLLM 兼容。您可以使用以下 Python 脚本测试 PyTorch NCCL 是否正常工作：([vLLM](https://docs.vllm.com.cn/en/latest/usage/troubleshooting.html?utm_source=chatgpt.com))

```text
import torch
import torch.distributed as dist

dist.init_process_group(backend="nccl")
local_rank = dist.get_rank() % torch.cuda.device_count()
torch.cuda.set_device(local_rank)
data = torch.FloatTensor([1,] * 128).to("cuda")
dist.all_reduce(data, op=dist.ReduceOp.SUM)
torch.cuda.synchronize()
value = data.mean().item()
world_size = dist.get_world_size()
assert value == world_size, f"Expected {world_size}, got {value}"
print("PyTorch NCCL is successful!")
```

如果测试失败，可能需要调整 NCCL 环境变量，例如：([vLLM](https://vllm.hyper.ai/docs/getting-started/troubleshooting/?utm_source=chatgpt.com))

```text
export NCCL_P2P_DISABLE=1
```

请注意，这些调整可能影响系统性能，建议仅作为临时解决方案。([vLLM](https://vllm.hyper.ai/docs/getting-started/troubleshooting/?utm_source=chatgpt.com))

##### ✅ 5. 使用分片模型（Sharded Model）
