# R26 · 单节点八卡服务器（W7900*8,48*8）DeepSeek-R1-AWQ-INT4部署
参考教程：[https://zhuanlan.zhihu.com/p/24178815248](https://zhuanlan.zhihu.com/p/24178815248)

1. 创建镜像命令

```text
docker run -dit \
    --name deepseek-671b-awq-in4 \
    --device=/dev/kfd \
    --device=/dev/dri \
    --group-add=video \
    --ipc=host \
    --shm-size=384g \
    -v /root/models:/app/models \
    -v /root/results:/app/vllm/benchmarks/results \
    -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
    -e VLLM_WORKER_MULTIPROC_METHOD=spawn \
    -e VLLM_USE_TRITON_FLASH_ATTN=0 \
    -e TRANSFORMERS_OFFLINE=1 \
    ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
    bash

```

1. 使用vllm Rocm版本加载模型

```text
python3 -m vllm.entrypoints.api_server \
  --model /app/models/DeepSeek-R1-awq \
  --served-model-name DeepSeek-R1 \
  --tensor-parallel-size 8 \
  --max-model-len 4096 \
  --max-num-seqs 8 \
  --max-num-batched-tokens 2048 \
  --gpu-memory-utilization 0.95 \
  --enforce-eager \
  --quantization awq \
  --dtype bfloat16 \
  --trust-remote-code \
  --port 8000

```

验证测试命令：

```text
python3 -m vllm.entrypoints.openai.api_server \
  --model /root/models/ds-qwq-32b-gguf/DeepSeek-R1-Distill-Qwen-32B-Q4_K_M.gguf \
  --tensor-parallel-size 8 \
  --max-model-len 4096 \
  --dtype float16 \
```

llama.cpp加载671b-GGUF格式模型
