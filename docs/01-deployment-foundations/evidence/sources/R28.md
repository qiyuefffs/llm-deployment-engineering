二、Docker部署配置

##### 步骤1：安装必要依赖

确保系统具备添加APT仓库的基础工具：

```text
sudo apt update
sudo apt install -y apt-transport-https ca-certificates curl software-properties-common
```

##### 步骤2：添加Docker官方仓库

​**​方案一：使用国内镜像源（推荐）**

**​**

```text
# 添加阿里云镜像源（适配国内网络）

sudo add-apt-repository "deb [arch=amd64] https://mirrors.aliyun.com/docker-ce/linux/ubuntu $(lsb_release -cs) stable"
```

五、创建镜像命令，启动镜像命令

1. 双卡（W7900*2,48*2GB）,16并发，deepseek-r1:32b模型，fp16精度

```text
docker run -itd --name deepseek-vllm-16 \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  -p 8000:8000 \
  -v /srv/llm/models:/app/models \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
  python3 -m vllm.entrypoints.api_server \
    --model /app/models/DeepSeek-R1-Distill-Qwen-32B \
    --tensor-parallel-size 2 \
    --served-model-name DeepSeek-R1-Distill-Qwen-32B \
    --max-num-seqs 16 \
    --max-num-batched-tokens 4096 \
    --max-model-len 4096 \
    --gpu-memory-utilization 0.85 \
    --disable-custom-all-reduce \
    --enforce-eager

```
