# R18 · AMD 780M-GPU 适配教程
1. 准备与安装

     安装AMD HIP SDK for Windows，更新AMD Software驱动

     AMD HIP 安装链接：

     [https://www.amd.com/zh-cn/developer/resources/rocm-hub/hip-sdk.html](https://www.amd.com/zh-cn/developer/resources/rocm-hub/hip-sdk.html)

   下载链接：[https://github.com/likelovewant/ROCmLibs-for-gfx1103-AMD780M-APU/releases](https://github.com/likelovewant/ROCmLibs-for-gfx1103-AMD780M-APU/releases)
