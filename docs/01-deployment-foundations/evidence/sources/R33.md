# R33 · Deepseek-R1-671b双节点部署
head节点镜像启动命令

```text
docker run -itd --name node-head-671 \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  --network host \
  -v /root/srv/llm/models:/app/models \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  -e LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
  bash -c "ray start --head --node-ip-address=<NODE_IP> --port=6379 --block"
```

worker节点镜像启动命令

```text
docker run -itd --name node-worker-671 \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  --network host \
  -v /root/srv/llm/models:/app/models \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  -e LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
  bash -c "ray start --address=<NODE_IP>:6379 --block"
```

进入docker镜像内部

```text
docker exec -it node-head-671 bash
```

ray集群状态验证

```text
ray status
```
