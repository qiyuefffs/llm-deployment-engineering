#### 优化历程

##### 测试 1: 基础配置

```text
LD_LIBRARY_PATH=/srv/llm/llamaCPP /srv/llm/llamaCPP/llama-server \
  --model "/srv/llm/models/Qwen3.6-35B-A3B-GGUF-BF16/BF16/Qwen3.6-35B-A3B-BF16-00001-of-00002.gguf" \
  --host 0.0.0.0 --port 8080 \
  --ctx-size 16384 \
  --n-gpu-layers 99 \
  --threads 16 --threads-batch 32 \
  --ubatch-size 1024 --batch-size 4096 \
  --cache-ram 0 --poll 50 --mlock
```

**结果:** 10.8 tok/s (92.30 ms/token)

##### 测试 2: Flash Attention + Cache Reuse

```text
# 添加参数:
--flash-attn on --cache-reuse 256
```

**结果:** 10.8 tok/s (无变化) **原因:**

- Flash Attention 对 Gated Delta Net 架构无效

- Cache reuse 不被 Qwen3.5-MoE 的 SSM/RNN 层支持

##### 测试 3: 增大 Batch + 减小 Context

```text
--ctx-size 8192 \
--threads-batch 64 \
--ubatch-size 2048 \
--batch-size 8192 \
--flash-attn on
```

**结果:** 10.1 tok/s (98.55 ms/token) - 略降 **分析:**

- KV cache 从 320 MB 降至 160 MB

- Compute buffer 从 1172 MB 增至 2312 MB

- 对 UMA 带宽瓶颈无实质影响

#### 性能对比

| 精度 | 大小 | 速度 | 延迟 | 显存占用 |
| --- | --- | --- | --- | --- |
| Q4_K_M | 21 GB | 58 tok/s | 17.1 ms | ~22 GB |
| BF16 | 65 GB | 10 tok/s | 92-98 ms | ~67 GB |

**速度比:** Q4_K_M 是 BF16 的 **5.8 倍**

#### 瓶颈分析

##### 内存带宽限制

- AMD 集成 GPU 使用统一内存架构 (UMA)

- 实际带宽: ~100 GB/s

- BF16模型文件约65 GB；每步实读取决于激活专家、共享层、KV与kernel

- 理论分析修订：带宽模型应为有效内存带宽÷每生成token实际读取的字节数。MoE只激活部分专家，不能以总文件大小或16 bytes/token推导速度；6–12 tok/s不是由原式可得的理论结果。

- 实际达到: **10 tok/s** (已达带宽上限)

##### 为什么 Q4_K_M 快 5.8 倍?

| 指标 | Q4_K_M | BF16 |
| --- | --- | --- |
| 模型大小 | 21 GB | 65 GB |
| 文件体积，非每步实读 | 21 GB | 65 GB |
| BPW (每权重比特) | 5.11 | 16.0 |
| 带宽利用率 | 高效 | 低效 (3x 数据量) |

#### 已尝试的优化手段

| 优化项 | 状态 | 效果 |
| --- | --- | --- |
| --n-gpu-layers 99 | ✅ 全层 GPU | 必须 |
| --flash-attn on | ✅ 已启用 | 对 SSM 架构无效 |
| --cache-reuse 256 | ❌ 不支持 | SSM 层不支持 KV reuse |
| ubatch 1024→2048 | ✅ 已测试 | 无提升 |
| ctx-size 16384→8192 | ✅ 已测试 | 节省 160 MB, 无速度提升 |
| threads-batch 32→64 | ✅ 已测试 | 无提升 |
| --mlock | ✅ 已启用 | 防止 swap |
| --poll 50 | ✅ 已优化 | 减少延迟 |

#### 结论

**BF16在这组已测参数中约10 tok/s。**当前实验未找到更快配置；未提供roofline或带宽计数器，不能宣称硬件性能极限。

##### 推荐方案

1. **生产环境:** 使用 Q4_K_M (58 tok/s, 精度损失需以目标任务验证)

2. **速度优先:** 使用 IQ4_XS (17.73 GB, 预计 65+ tok/s)

3. **BF16 仅适用于:**

  - 精度敏感的研究场景

  - 有独立 VRAM 的 GPU (如 RTX 4090 24GB + PCIe 带宽更高)

  - 批量推理 (通过增大 parallel slots)
