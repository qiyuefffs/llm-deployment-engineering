# R32 · 双节点，再次推理DS-70B
以下是一个**完整详细的双节点部署方案**，用于分布式推理 DeepSeek-R1-Distill-Llama-70B 模型，**每个节点仅使用 2 张指定 GPU 卡**，共使用 4 张卡完成 Tensor Parallelism + Pipeline Parallelism。

---

### 🎯 目标设定

| 项目 | 内容 |  |
| --- | --- | --- |
| 节点数 | 2 |  |
| 每节点总 GPU | 8 张 |  |
| 每节点用于推理的 GPU | 2 张（0 和 1） |  |
| 总使用 GPU | 4 张 |  |
| 模型 | DeepSeek-R1-Distill-Llama-70B |  |
| 显存需求 | 每卡需 48GB（你已有） |  |
| 并行方式 | Tensor Parallelism（TP）= 2，Pipeline Parallelism（PP）= 2 |  |
| 推理框架 | vLLM + Ray（rocm） |  |

---

### 🧱 基础准备

#### ✅ 模型提前下载到两个节点：

确保两个节点都在以下路径准备好了模型：

```text
/root/models/DeepSeek-R1-Distill-Llama-70B
```

下载方式（任选其一）：

```text
# 进入模型目录
mkdir -p /root/models && cd /root/models
# 使用 huggingface-cli 下载（假设你已登录）
huggingface-cli download deepseek-ai/DeepSeek-R1-Distill-Llama-70B --local-dir DeepSeek-R1-Distill-Llama-70B
```

---

### 🛠 部署步骤（双节点）

#### 🧩 共用参数（通用）

##### ✅ 环境变量（通用）

```text
-e ROCR_VISIBLE_DEVICES=0,1 \        # 限制只使用 GPU 0 和 1
-e HSA_OVERRIDE_GFX_VERSION=11.0.0 \ # 配合 ROCm11+
-e LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH
```

---

#### 🚀 步骤一：启动头节点（ IP = `<NODE_IP>`）

##### ✅ 脚本 `start_head.sh`

```text
#!/bin/bash
docker run -itd --name node-head-2 \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  --network host \
  -v /root/models:/app/models \
  -v /root/.cache/huggingface:/root/.cache/huggingface \
  -e ROCR_VISIBLE_DEVICES=0,1 \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  -e LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
  bash -c "ray start --head --node-ip-address=<NODE_IP> --port=6379 --block"
```

---

#### 🚀 步骤二：启动工作节点（ IP = `<NODE_IP>`）

##### ✅ 脚本 `start_worker.sh`

```text
#!/bin/bash
docker run -itd --name node-worker-2 \
  --device=/dev/kfd \
  --device=/dev/dri \
  --group-add=video \
  --ipc=host \
  --shm-size=16g \
  --network host \
  -v /root/models:/app/models \
  -v /root/.cache/huggingface:/root/.cache/huggingface \
  -e ROCR_VISIBLE_DEVICES=0,1 \
  -e HSA_OVERRIDE_GFX_VERSION=11.0.0 \
  -e LD_LIBRARY_PATH=/usr/local/lib:$LD_LIBRARY_PATH \
  ghcr.io/embeddedllm/vllm-rocm:v0.8.2-18ed313 \
  bash -c "ray start --address=<NODE_IP>:6379 --block"
```

---

#### ✅ 检查集群状态（在头节点执行）

```text
docker exec -it node-head ray status
```

应显示两个节点都连接成功，并识别 4 个 GPU。

---

#### 🚀 步骤三：在头节点启动分布式推理服务

##### ✅ 命令（进入容器后执行）

```text
docker exec -it node-head bash
```

然后在容器内部运行：

```text
python3 -m vllm.entrypoints.api_server \
  --model /app/models/DeepSeek-R1-Distill-Llama-70B \
  --served-model-name DeepSeek-R1 \
  --tensor-parallel-size 8 \
  --pipeline-parallel-size 2 \
  --max-num-seqs 16 \
  --max-model-len 4096 \
  --max-num-batched-tokens 4096 \
  --gpu-memory-utilization 0.85 \
  --disable-custom-all-reduce \
  --host 0.0.0.0 \
  --port 8000
```
