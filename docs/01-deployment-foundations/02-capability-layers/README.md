## 资料分工

- 主框架：技术定义、组件结构、参数、判断条件与工程输出。
- 平台专题：具体后端的机制、配置与故障解释。
- [完整工程记录](../engineering/README.md)：具体GPU的执行顺序、优化过程和50份FlowUs技术原文。
- [结果与来源](../evidence/README.md)：历史环境、结构化数字、核算与缺项。

## 适配顺序

```text
设备与最小计算 → 模型完整性 → 单请求正确 → API/SSE/异常
 → 基线与峰值 → 对照优化 → 质量/性能/资源验收 → 交付/回滚
```

模型尚不能正确执行时，先处理支持与功能；进入优化后固定模型、输入和计时边界。各设备的环境与数字不跨记录合并成一套运行组合。
